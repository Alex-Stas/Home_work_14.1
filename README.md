Project: Home Work OOP 04_25


Module category.py with class Category: 
    объявляет класс Category c категорией товаров и полями:
        name - название категории
        description - описание категории
        products - список товаров в данной категории
    дополнительно два глобальных значения 
        category_count - количество категорий
        product_count - количество товаров

Module product.py with class Product: 
    объявляет класс Product c описанием товара и полями:
        name - название товара
        description - описание товара
        price - ценой за единицу
        quantity - количество

Automatic tests are added for all modules.

    тест на подсчет количества категорий
    тест на подсчет количества товаров

    тест на инициализацию класса Product
