*** - обновления от 02.06.2025

Module category.py with class Category: 
    объявляет класс Category c категорией товаров и полями:
        name - название категории
        description - описание категории
        products - список товаров в данной категории
            дополнительно два глобальных значения 
        category_count - количество категорий
        product_count - количество товаров
            список товаров имеет приватный режим доступа
        реализован метод setter - add_product для добавления товара с проверкой, что добавляемый объект является
            объектом Product, в противном случае выводится сообщение и объект не добавляется
        Реализован геттер для products - возвращающий строку по шаблону: "Название продукта, X руб. Остаток: X шт.\n"
        *** с дополнительной модификацией - замена строки на метод __str__ из Products
        Реализован геттер для products - возвращающий список продуктов списком products_in_list
        *** Реализован метод __str__ для вывода названия и количества продуктов в категории
        

Module product.py with class Product: 
    объявляет класс Product c описанием товара и полями:
        name - название товара
        description - описание товара
        price - ценой за единицу
        quantity - количество
        цена имеет приватный режим доступа
        реализован метод new_product для добавления товара из словаря
        реализован геттер для price - возвращающий цену
        реализован сеттер для price - дополнительно проверяющий значение цены, обновление происходит только если 
            цена положительная, в противном случае выводится сообщение и цена не меняется
        *** Реализован метод __str__ для вывода названия, цены и остатка продукта
        *** Реализован метод __add__ для сложения общей стоимости продуктов (количество * цена единицы)

*** Module product_iteration.py with class ProductIterator:
    для перебора товаров одной категории, например в цикле for.
    Принимает на вход объект класса категории и производит итерацию по товарам, которые хранятся в данной категории.
